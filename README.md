# Catraca

Venda de ingressos para eventos pequenos (shows em bar, workshops, meetups), construída em modo agente a partir do
brief da fundadora, com Spec-Driven Development: PRD → spec/plano/contrato por feature → implementação por agentes
→ avaliação independente.
